# Site Patterns

这个目录存放按域名沉淀的网站操作经验，目标是减少重复试错。

只记录已经验证过的事实：

- 平台特征：渲染方式、登录要求、反爬限制、资源加载模式
- 有效模式：稳定可用的 URL 规律、提取方式、交互策略、截图/抓包入口
- 已知陷阱：无效参数、容易失败的入口、会触发风控的操作

不要写未验证的猜测，不要把一次偶发成功包装成通用规律。

## 使用时机

1. 确定目标网站后，先检查这里是否已有对应域名文件
2. 如果有，优先读取并按其中经验尝试
3. 如果经验失效，回退通用模式，并在确认新规律后更新文件
4. 如果没有，按通用模式完成任务，确认有稳定模式后新增文件

## 命名规则

- 一个主域名一个文件，如 `xiaohongshu.com.md`
- 必要时可用同一文件覆盖多个别名域名，在 frontmatter 的 `aliases` 中声明

## 文件格式

复制 [`TEMPLATE.md`](./TEMPLATE.md) 作为起点。
